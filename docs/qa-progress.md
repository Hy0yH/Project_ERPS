# ERPS QA 진행 기록

## 2026-10-26 KST — 개선·보완·추가 기능과 API 의존성 조사

요청 범위: QA 실행 프롬프트를 기준으로 프로젝트의 개선점·보완점·추가점과 상위 API가 필요한 위치를 조사·정리. 이번 실행에서는 기능을 수정하거나 운영 DB를 갱신하지 않았다.

### 시작 상태와 보존

- README, 플레이어 분석·수집·타입·스타일·테스트 등에 기존 수정 및 미추적 파일이 있었음. 기존 변경을 보존함.
- 저장소와 상위 경로에서 적용할 AGENTS.md는 발견하지 못했으며 .agents는 비어 있었음.
- 기존 수집 서버가 3101에서 응답하는 것을 확인했으나 후속 접근 시 연결이 거부됨. 종료 원인은 확인하지 않았고 이번 작업에서 해당 서버를 종료·재시작하지 않음.
- 현재 소스의 화면 확인용으로 127.0.0.1:3000에 임시 개발 서버를 실행했고 점검 후 해당 실행 세션만 종료함.
- 개발 서버가 자동 변경한 next-env.d.ts의 routes 참조는 시작 전 내용으로 복원함. 업무 코드와 설정 변경 없음.
- 자격 증명 값은 출력하지 않고 설정 유무만 확인. 로컬 게임 API·Supabase·관리/수집 토큰 설정 존재, OpenAI 키 없음. 배포 환경은 별도 미확인.

### 미실시·미검증

- 실제 플레이어에 대한 신규 분석·개인화 추천·강제 갱신: 수집·캐시 쓰기를 피하기 위해 고정 표본/모의 호출로 대체. 실제 최신 비교군 점수 검증은 별도 필요.
- 패치 import 실제 저장, 운영 수집·스냅샷 재실행, DB 권한 변경·마이그레이션: 실행하지 않음.
- 프로덕션 빌드: 수집 서버가 사용하는 공유 산출물을 보존하기 위해 이번 조사에서는 실행하지 않음. 과거 빌드 성공을 이번 통과로 대체하지 않음.
- 현재 게임 API 키 종류/개별 승인 한도/MMR 필드 권한과 운영 DB의 anon/authenticated 실효 권한: 확인하지 않음.
- OpenAI 실제 호출: 로컬 키 없음. 기존 fallback·후보 보호 테스트만 포함. 상위 모델 비교·비용/지연 실측 미실시.
- 전체 키보드·스크린리더·대비·모든 모바일 상태 및 0/1/2 팀원 전체 E2E 매트릭스: 이번 실행에서 전부 완료하지 않음.

### 출처 확인과 API 판단

- 공식 개발자 포털 Getting Started를 브라우저로 직접 확인: Personal Key 1회/초, Production Key 50회/초, 제공자에게 제품 설명 후 신청. 현재 프로젝트의 키 등급은 미확인.
- 공식 게임 API 명세: 일부 MMR 필드의 제한 접근, 최근 전적·닉네임/UID 범위, 장비·스킬 순서 등 확인.
- OpenAI Docs 스킬로 공식 모델 기능·구조화 출력·사용 한도 문서를 확인. 현재 기능의 상위 모델 필수성은 확인되지 않음.
- Computer Use 스킬과 브라우저 도구로 화면을 점검. 실제 사이트의 데이터·권한·설정을 변경하지 않음.
- Supabase 공식 쿼리 최적화 문서를 확인. DB 요금제 변경은 실제 쿼리·자원 측정 이후의 판단으로 남김.

## 2026-10-27 KST — 추가 기능 구현과 재검증

요청: 앞서 정리한 추가 기능을 실제 프로젝트에 반영. [구현 범위와 한계](additional-features-2026-10-27.md), [백로그 후속 상태](qa-backlog.md#2026-10-27-추가-기능-구현-후-상태)에 상세 기록했다.

- 티어표 탐색·필터 유지, 선택 픽 분석/캐시 분리, 경기 상세, 팀원 닉네임·무기, 점수 분해·후보 비교, 패치별 보관 통계, 운영 상태를 추가했다.
- 분석 단계 스트림·프로세스 내부 작업 조회/병합, 수동 기기 이력·메모·비중복 기록 비교, JSON/CSV·조회 링크, 규칙 기반 근거 질문을 구현했다. 영구 큐/계정 동기화/자유 대화/영상은 별도 범위다.
- 추천 scope·없는 메타 성적·상세 rankScope 유지를 보완했다. 관리자/수집 토큰 미설정·예제값 차단을 추가했다. 로컬 두 토큰이 예제값인 것을 확인했으며 값을 변경하지 않았다.
- 집계 250행 배치와 실행/실패 단계 기록을 추가했지만 운영 재집계를 실행하지 않았고 QA-005 해결 판정을 보류한다. 읽기 전용 조회에서도 현재 실험체/조합 시점 차이가 남아 있다.
- 기존 사용자 수정은 보존했다. 기존 `.next`를 덮지 않고 `.next-qa`에서 프로덕션 빌드·로컬 검증했다. Next가 자동 수정한 next-env.d.ts와 tsconfig.json은 검증 후 원래 내용으로 복원했다. 이번에 실행한 임시 검증 서버만 종료했다.

검사 결과: 전체 **33개 파일·212개 테스트 통과**, 타입 검사와 프로덕션 빌드 성공. 기존 실전 고정 표본의 독립 계산 감사는 **328개 검사·실패 0·147개 고유 경기**다. 이 감사는 비교군 미사용 조건으로, 운영 비교군 정확도 검증과 구분한다.

실 DB 읽기 경로의 브라우저에서는 검색→상세 6,344판 일치, 6개 보관 패치, 팀원 무기 제약 추천·점수 분해·후보 비교를 확인했다. 미존재 실험체 HTTP 404도 확인했다. 개인 분석은 별도 프록시가 외부 수집·DB 쓰기를 차단하는 고정 표본으로 40→20판 전환, 상세·저장·질문·실제 다운로드를 검증했다. 추천 비교를 펼쳤을 때의 모바일 문서 가로 넘침을 수정하고 390px 화면에서 문서 폭 375px, 표 내부 스크롤을 확인했다.
