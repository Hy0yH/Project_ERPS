## 2026-10-29 수집 안정성 후속 구현

- **QA-005 / ERPS-006:** 집계 준비 배치·세 테이블의 트랜잭션 공개·DB 실행 lease를 구현했다. 실제 Postgres 엔진에서 후속 테이블 오류·누락 배치·기간 불일치 시 이전 집계 보존을 검증했다. 운영 DB 적용·대규모 운영 재집계·다중 연결 부하는 남아 있으므로 기존 운영 장애를 해결 완료로 올리지 않는다. 영구적인 배치 계산 재개는 별도 후속이다.
- **신규 수집 회귀 검사:** ERPS-032~036의 중복·부분 완료·지연 재시도·종료 기록·전체 실패 상태를 보완하고, 선택 재개 API의 인증·입력 경계도 검사했다. 전체 43파일·294테스트·타입 검사·분리된 프로덕션 빌드 통과. 운영 수집이나 DB 쓰기는 이번 작업에서 수행하지 않았다.
- **QA-010 / QA-015:** 공유 API 키 합산 할당량·사용자/IP 단위 제한은 이번 DB lease와 다른 범위이며 기존 후속 조건을 유지한다.
