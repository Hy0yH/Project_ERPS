# 플레이어 피드백 개선

## 목적

조회 시점의 현재 패치 전적으로 관측 근거 → 점검 가설 → 확인해 볼 행동 → 기록 비교 안내를 제공한다. 화면에서는 이를 **최근 전적 기반 점검 제안**으로 부른다. 수행 여부를 추적하지 않으며, 제안의 효과를 평가하지 않는다. 경기 종료 통계로 실제 장면과 인과관계를 확정하지 않는다.

## 구현 범위

1. **선정 결과 보호**: 강점과 점검 제안의 후보 ID·근거 지표 집합을 각각 검증한다. 후보 이동·추가·부분 근거·중복을 허용하지 않으며, 누락된 후보도 서버의 순서대로 유지한다. AI는 기본 요약과 보충 설명만 작성하고 관측 수치·제목·가설·행동 제안·기록 비교 안내를 변경하지 못한다. 숫자와 보장 표현이 포함된 보충 설명은 사용하지 않는다. 자연어 설명의 모든 의미를 자동 검증하는 것은 아니므로 핵심 근거와 행동 제안은 서버가 작성한다.
2. **현재 패치로 판단 범위 제한**: 개인 지표·주력 픽·강점·점검 제안·비교군 모두 현재 패치가 확인된 경기만 사용한다. 이전 패치와 패치 미확인 기록을 제외하며 이전 패치의 좋은/나쁜 기록으로 표본을 채우지 않는다. 전체 또는 해당 지표의 개인 기록이 10판 미만이면 플레이스타일 비교 점수와 점검 제안을 보류한다. 현재 패치 기록이 전혀 없으면 기존의 기록 없음 응답을 반환한다. 현재 패치 자체를 확인하지 못하면 분석 불가 응답을 반환한다.
3. **판단 상태와 범위 공개**: 제안 있음, 현재 패치 개인/비교 표본 부족, 낮은 지표가 있으나 행동 근거 부족, 충분한 표본에서 뚜렷한 약점 없음으로 구분한다. 개인 기록 중 제외한 경기 수, 현재 패치의 주력 픽/전체 픽, 실험체·무기, 개인 경기 수와 비교군 규모·신뢰도를 표시한다. 같은 픽·역할군 비교는 주력 픽 개인 기록을 사용하며, 유사 MMR 비교는 현재 패치 전체 픽 기록을 사용한다.
4. **맥락에 따른 행동 제안**: 피해량·킬 관여율·정상 성장, 피해량·성장·파밍의 동반 저하, 성장·파밍 동반 저하를 구분한다. 조합할 때 개인 범위와 경기 수가 같아야 한다. 표본이 충분하고 35 미만이며 TOP3 기록과 연관된 행동 지표를 제안의 기준으로 사용한다. 정상 성장 지표는 맥락 설명에만 포함할 수 있다. 성장·파밍의 중복 제안을 줄이고 총 2개로 제한한다.
5. **최근 기록 비교**: 동일 패치·실험체·무기에서 유효한 20경기가 확보될 때 최근 10경기와 이전 10경기를 비교한다. 조회 시점에 확보된 개인 실제 수치의 변화이며, 제안을 받은 이후의 경기나 수행 여부를 연결한 결과가 아니다. 화면에도 수행 여부 미추적과 효과 평가가 아니라는 안내를 항상 표시한다. 순위 변동성에는 이 비교를 표시하지 않는다.
6. **기존 결과 갱신**: 분석 캐시 버전은 19다. 이전 패치 혼합·이전 명칭·이전 계산 결과를 재사용하지 않는다. DB 스키마 변경은 필요하지 않다. 수집/분석 상한은 최대 50경기다. 실제 통계 확장과 비교 점수·관측 방향 일치 검증은 [수치 검증 문서](player-analysis-validation-2026-10-26.md), 실험체별 성적 등급은 [등급 문서](player-pick-ratings.md)를 참고한다.

## 후속 확장

수행 체크, 장기 분석 이력, 제안 전후의 비중복 경기 비교는 별도의 저장 모델과 평가 기준이 필요하다. 현재 제공하는 최근 10/이전 10경기 비교는 수행 이후를 추적한 실험 결과가 아니다.

## 검증

- 개인 범위가 다른 지표를 결합하지 않는지 확인한다.
- 이전 패치와 패치 미확인 기록이 개인 분석·비교군에서 제외되는지 확인한다.
- 현재 패치 개인 기록이 10판 미만이면 이전 기록 수와 관계없이 판단을 보류하는지 확인한다.
- 낮은 신뢰도와 지원 활동을 강점/점검 제안에서 제외하는지 확인한다.
- 표본 부족·행동 근거 부족·뚜렷한 약점 없음 상태를 구분한다.
- 최근 비교가 서로 겹치지 않는 동일 패치·픽 10경기씩인지 확인한다.
- AI가 후보를 이동/추가하거나 근거 일부만 반환할 때 기본 결과를 보존한다.
- API 키 없음, 파싱 실패, 시간 초과에서 기본 피드백을 반환한다.
- 타입 검사, 관련 회귀 테스트, 전체 테스트, 프로덕션 빌드를 실행한다.
