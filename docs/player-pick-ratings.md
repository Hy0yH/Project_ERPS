# 플레이어의 실험체 성적 등급

사용자가 선택한 순서는 **S → A+ → A → B+ → B → C+ → C → D+ → D → F+ → F**다. 플레이어 분석 화면 상단에 사용 횟수 상위 3개 실험체·무기를 큰 카드로 표시한다. 나머지는 기본으로 접힌 `다른 실험체 펼쳐보기`에 모아 등급·점수·경기 수·추가 경기 안내를 표시하고, 각 행을 펼치면 상세 기록과 평가 근거를 볼 수 있다. 같은 실험체라도 무기가 다르면 개별 평가한다.

## 평가 범위와 의미

현재 패치가 확인된 최근 최대 50경기 안에서 해당 실험체·무기의 **경기 결과**를 평가한다. 사용 기록이 1판이라도 있으면 현재 등급을 표시한다. 같은 패치·비슷한 MMR대 전체 픽의 플레이어별 성적 분포가 공통 비교 기준이다. 기본 500 MMR 구간이 부족하면 서비스가 확보한 인접 MMR 구간을 사용한다. 비교 기록이 전혀 없으면 개인 경기 결과의 환산 점수로 평가하며, 카드의 근거에서 두 방식을 구분한다. 플레이어의 실험체 자체에 대한 메타 티어나 확정된 숙련도를 뜻하지 않는다.

평가 항목은 평균 순위 50%, TOP3 비율 35%, 승률 15%다. 세 항목은 같은 경기 결과를 서로 다른 관점에서 요약한 정책 가중치이며, 독립적인 세 종류의 성과 증거로 해석하지 않는다. 역할에 따라 크게 달라지는 피해량은 공통 성적 점수에 섞지 않고, 해당 실험체의 분당 피해·경기당 사망·평균 실제 RP를 근거 기록으로 함께 보여준다. 전투·지원 특성은 기존 상세 지표에서 확인할 수 있다.

## 계산

1. 개인 기록은 해당 실험체·무기만 사용한다. 이전 패치와 미확인 패치 기록은 기존 분석 단계에서 제외한다.
2. 비교군은 지표별로 플레이어마다 평균 순위·TOP3·승률을 계산해, 경기를 많이 한 한 명이 분포를 지배하지 않게 한다.
3. 각 개인 지표의 백분위를 계산한다. 평균 순위는 낮을수록 좋은 방향으로 반전한다. 동률은 절반의 순위로 처리한다.
4. 비교 기록이 있을 때 표본 보정 계수는 `sqrt(min(개인 경기 / 20, 1) × min(비교 플레이어 / 50, 1))`다. 비교 표본이 적어도 이 보정으로 현재 등급을 계산한다.
5. 항목 점수는 `50 + (백분위 − 50) × 보정 계수`이며 소수점 첫째 자리로 표시한다. 항목별 점수에 가중치를 곱해 합산한 뒤 다시 소수점 첫째 자리로 반올림한다.
6. **화면에 표시하는 점수**를 아래 구간에 대응시킨다. 반올림해 90.0점인데 A+로 표시되는 모순을 방지한다.

비교 기록이 없을 때는 평균 순위의 원점수를 `clamp((8 − 평균 순위) / 7 × 100, 0, 100)`, TOP3와 승률의 원점수를 각각 `비율 × 100`으로 환산한다. 표본 보정 계수는 `sqrt(min(개인 경기 / 20, 1))`를 사용하고 같은 가중치로 합산한다. 이 경우 `basis=match_results`이며 비교 평균과 백분위는 미수집으로 유지한다. 비교 결과를 지어내거나 모든 실험체에 일괄적으로 B를 부여하지 않는다.

| 등급 | 점수 |
| --- | --- |
| S | 90–100 |
| A+ | 80 이상 90 미만 |
| A | 70 이상 80 미만 |
| B+ | 60 이상 70 미만 |
| B | 50 이상 60 미만 |
| C+ | 40 이상 50 미만 |
| C | 30 이상 40 미만 |
| D+ | 20 이상 30 미만 |
| D | 10 이상 20 미만 |
| F+ | 5 이상 10 미만 |
| F | 0 이상 5 미만 |

## 표본과 표시 상태

- 해당 실험체·무기 기록 **1판부터** 현재 등급과 점수를 표시한다. 적은 기록은 50점 쪽으로 보수적으로 보정한다.
- 비교 지표의 최소 **50경기·30명** 조건은 등급 확정에 적용한다. 이 기준에 미달해도 현재 등급을 표시한다.
- 1–19판에는 `등급 확정까지 N판 더 필요`로 개인 20판까지 남은 경기 수를 안내한다.
- 20판 이상이어도 비교 표본의 보정 계수가 0.85 미만이면 `등급 확정을 위한 비교 데이터 수집 중`으로 안내한다. 개인 경기와 비교 표본이 모두 부족하면 두 안내를 함께 표시한다.
- 20판 이상이며 모든 평가 항목의 보정 계수가 0.85 이상이면 추가 경기 안내를 표시하지 않는다.
- 비교 표본만 부족한 경우에는 개인 경기 수를 임의로 요구하지 않는다. 비교 기록이 전혀 없거나 개인 기록이 10판 미만이면 신뢰도를 낮게 기록한다.
- 항목별 가중치·개인 값·비교 평균·비교 표본·보정 점수를 카드에서 펼쳐 볼 수 있다.
- 추가 지표의 미수집은 `미수집`으로 표시하며 실제 0과 구분한다.

등급은 전적과 비교군이 갱신되면 달라질 수 있다. 가중치와 구간은 이 기능의 명시적인 정책이며, 장기 숙련도나 향후 랭크 상승을 예측하는 모델로 검증한 값은 아니다.

## 겜덕후 적용 예시

2026-10-27 02:21 KST에 확보한 현재 패치 21경기 스냅샷에 적용했다.

| 실험체·무기 | 경기 | 결과 |
| --- | ---: | --- |
| 유스티나·석궁 | 13 | B+ · 61.9점 · 등급 확정까지 7판 더 필요 |
| 코렐라인·아르카나 | 3 | B · 53.8점 · 등급 확정까지 17판 더 필요 |
| 아드리아나·투척 | 3 | B · 59.6점 · 등급 확정까지 17판 더 필요 |
| 마커스·도끼 | 2 | C+ · 44.0점 · 등급 확정까지 18판 더 필요 |

유스티나는 평균 순위 3.54위·TOP3 46.2%·승률 15.4%다. 비교군 243경기·210명의 플레이어별 성적 분포와 비교한 보정 점수는 각각 59.6·57.7·79.2이며, `59.6 × 0.5 + 57.7 × 0.35 + 79.2 × 0.15 = 61.875 → 61.9점`이다.

## 검증과 운영

- 등급 11단계의 경계·반올림, 1/9/10/20판 처리, 비교 플레이어 부족·비교 기록 부재, 무기별 분리, 이전 패치 제외, 역할별 피해 차이와 실제 0/미수집을 테스트했다.
- 입력 순서와 관계없이 사용 횟수 상위 3개가 큰 카드로 표시되고, 나머지 5개가 접힌 목록에 보존되는 8개 픽 사례를 확인했다. 3개 이하면 펼침 영역을 만들지 않는다.
- 전체 **26개 파일·180개 테스트**, 타입 검사, 프로덕션 빌드가 통과했다.
- 앞서 확보한 5명 전적과 겜덕후의 추가 경기 스냅샷에 독립 계산식을 적용해 **601개 검증 항목**이 일치했다. 그중 새 등급의 점수·등급·상태 검증은 90개다. 두 스냅샷에는 중복되는 기존 경기가 있으므로 601을 고유 경기 수로 해석하지 않는다.
- 데스크톱과 390px 모바일에서 모스트 3개·나머지 목록·행별 상세·기준표·평가 근거 표시를 확인했다. 펼침 영역의 키보드 조작도 확인했다.
- 등급 도입 시 분석 캐시 버전은 **19**였으며, 선택 픽 분석·경기 상세를 추가한 현재 버전은 **20**이다. 적은 경기에도 등급이 포함되도록 이전 결과를 재계산한다. 기존 캐시 테이블의 JSON을 사용하며 추가 DB 마이그레이션과 등급 계산을 위한 별도 외부 API 조회는 필요 없다. 등급은 서버 계산 결과이며 AI가 변경하지 않는다.

주요 구현은 `lib/player-pick-evaluation.ts`, `components/PlayerPickRatings.tsx`이며 기존 백분위·표본 보정 함수는 `lib/player-analysis-score.ts`로 분리해 공유한다. 독립 검증 결과는 [최신 등급 검증 JSON](evidence/player-pick-ratings-v19-2026-10-27.json)에 있다.
